## 🚀 Featured Projects

### 01 · Pedestrian Intention Detection

**Anticipating pedestrian crossings with calibrated predictions and temporal fusion.**

Built on the **JAAD driving dataset of 346 annotated video clips**. I owned the anticipation and temporal-fusion stages, combining a weighted Random Forest model, isotonic calibration, and temporal smoothing.

| Metric | Frame-wise XGBoost Baseline | Enhanced Pipeline |
| :--- | :---: | :---: |
| Recall | 0.84 | **0.93** |
| F1 score | 0.83 | **0.86** |

- Achieved an **average warning lead time of 1.59 seconds**.
- Reduced frame-to-frame prediction flicker using sliding-window fusion, hysteresis thresholds, and minimum-run merging.

**Stack:** `Python` `scikit-learn` `XGBoost` `Random Forest`
